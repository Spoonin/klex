# klex

Client-only mobile-first веб-приложение для наложения текстовых надписей и логотипов на видео в браузере.

## Language

**Layer (Слой)**:
Элемент композитинга над видео, содержащий одну текстовую надпись, её стилевые свойства, координаты на кадре и временные границы показа (вход, выход, fade).
_Avoid_: Элемент, дорожка, титр, блок

**Plate (Плашка)**:
Фоновая контрастная подложка под текстом надписи, обеспечивающая читаемость на любом видеоряде.
_Avoid_: Фон, подложка, плашка-фон, заливка блока

**Stroke (Обводка)**:
Внешний контур символов текста надписи заданного цвета и толщины.
_Avoid_: Контур, рамка, бордер

**Frame Height Fraction (Доля высоты кадра)**:
Относительная единица измерения кегля шрифта и вертикальных смещений, масштабируемая под любое целевое разрешение рендера.
_Avoid_: Пиксели (px), pt, em, rem (в контексте хранения размера)

**Scrub (Скраб)**:
Ручная покадровая навигация по таймлайну видео для позиционирования и предпросмотра без потокового воспроизведения.
_Avoid_: Playback, перемотка, воспроизведение

**Trim Window (Диапазон обрезки)**:
Временной отрезок исходного видео `[trimIn, trimOut]` длительностью не более 120 секунд, синхронно отсекающий видеокадры и аудиопакеты при экспорте.
_Avoid_: Cut, кроп, срез

**Logo (Логотип)**:
Одно растровое изображение, накладываемое на протяжении всего экспортируемого видео или каждого видео Пакета.
_Avoid_: Watermark, водяной знак, графический Layer

**Batch (Пакет)**:
Упорядоченный набор независимых исходных видео с одним Логотипом; каждое видео создаёт отдельный результат и не склеивается с соседними.
_Avoid_: Последовательность, плейлист, монтаж, объединённое видео

**Batch Default (Настройки Пакета)**:
Общие значения положения и вида Логотипа, наследуемые каждым видео Пакета при отсутствии соответствующего Переопределения видео.
_Avoid_: Глобальные настройки, шаблон, пресет

**Video Override (Переопределение видео)**:
Значение отдельного свойства Логотипа для одного видео Пакета, заменяющее только соответствующее значение Настроек Пакета.
_Avoid_: Индивидуальные настройки, копия настроек, конфигурация видео

**Logo Anchor (Якорь логотипа)**:
Ближайшая к Логотипу каноническая точка кадра: один из четырёх углов или центр.
_Avoid_: Квадрант, привязка, позиция

**Logo Offset (Смещение логотипа)**:
Пара расстояний по горизонтали и вертикали от Якоря логотипа до соответствующего угла Логотипа или его центра, измеренная в долях кратчайшей стороны кадра.
_Avoid_: Координаты, Logo Margin, отступ от края

**Safe Margin (Безопасный отступ)**:
Одинаковая для четырёх сторон внутренняя граница кадра, которую Логотип не может пересекать ни одной своей частью.
_Avoid_: Padding, рамка, Logo Offset

**Logo Size (Размер логотипа)**:
Длина большей стороны Логотипа, выраженная как доля кратчайшей стороны кадра.
_Avoid_: Ширина, высота, пиксельный размер
