# klex

Mobile-first веб-приложение для наложения текстовых надписей на видео. Работает целиком на клиенте: без сервера, без загрузки видео куда-либо.

## Статус

Реализован пошаговый сценарий «Видео → Надписи → Экспорт». Редактор поддерживает несколько текстовых слоёв, Scrub, отдельные временные границы каждого Layer, Trim Window и прямое позиционирование на предпросмотре. Экспорт открывается только после готового предпросмотра.

Выбранный MP4/MOV обрабатывается в Dedicated Web Worker через WebCodecs, WebGL2 и Mediabunny. Все видимые Layer компонуются с учётом исходной временной шкалы и fade, AAC-аудио копируется в итоговый MP4 без перекодирования.

Для локального запуска:

```bash
pnpm install
pnpm dev
```

Ход работы — на [карте wayfinder](https://github.com/Spoonin/klex/issues/1): там же зафиксированы принятые решения, границы первой редакции и то, что сознательно оставлено за её пределами.

## Направление

- Композитинг на WebGL2, текст растеризуется через Canvas2D — браузер берёт на себя шейпинг, unicode и цветные emoji.
- Декодирование и кодирование через WebCodecs; аудиодорожка копируется без перекодирования.
- Экспорт `.mp4` с потолком 1080p, пресеты под публикацию в соцсети.
- Инварианты проекта сосредоточены в `editor-project`, а покадровый план композиции — в `composition`; UI и Worker используют одни и те же правила времени.
