# klex

Mobile-first веб-приложение для наложения текстовых надписей на видео. Работает целиком на клиенте: без сервера, без загрузки видео куда-либо.

## Статус

Кода пока нет. Проект находится на стадии проектирования — идёт выработка спецификации первой редакции.

Ход работы — на [карте wayfinder](https://github.com/Spoonin/klex/issues/1): там же зафиксированы принятые решения, границы первой редакции и то, что сознательно оставлено за её пределами.

## Направление

- Композитинг на WebGL2, текст растеризуется через Canvas2D — браузер берёт на себя шейпинг, unicode и цветные emoji.
- Декодирование и кодирование через WebCodecs; аудиодорожка копируется без перекодирования.
- Экспорт `.mp4` с потолком 1080p, пресеты под публикацию в соцсети.
